# 🖥️ ManyDeck `v1.1.0`

**ManyDeck** — панель удалённого управления компьютером через Telegram. Полностью кнопочный интерфейс: никаких команд вручную — только нажатия.

## ✨ Возможности

| Раздел | Функция | Описание |
| :--- | :--- | :--- |
| **🖥️ Система** | Нагрузка | CPU, RAM, аптайм, диски |
| | Процессы | Список с RAM/PID, поиск по имени |
| | Скриншот | Снимок экрана прямо в чат |
| | Убить процесс | По имени или PID |
| | Активное окно | Заголовок окна в фокусе |
| | Буфер обмена | Содержимое clipboard |
| **⚙️ Действия** | Запустить прогу | По имени или команде |
| | Ввод текста | Вставка в активное окно |
| | Ввод + Enter | Вставка с мгновенным Enter |
| | Горячая клавиша | `win+l`, `alt+f4`, `ctrl+shift+esc` и т.д. |
| | Alt+Tab | Переключение между окнами |
| | Окошко с ошибкой | Системный MessageBox с нужным текстом |
| **🔊 Звук** | Громкость | Установка уровня 0–100% |
| | Mute / Unmute | Выключение и включение звука |
| **🔒 Питание** | Блокировка | Win+L |
| | Спящий режим | Гибернация |
| | Перезагрузка | Через 5 сек, с отменой |
| | Выключение | Через 5 сек, с отменой |
| **📁 Файлы** | Браузер | Навигация по дискам и папкам |
| | Скачать | Получить файл с ПК в Telegram (до 50 MB) |
| | Загрузить | Отправить файл боту → сохранится на ПК |
| **🌐 Сеть** | IP-адрес | Исходящий IP |
| | Интерфейсы | Все адаптеры с адресами |
| | Соединения | Активные TCP с именем процесса |
| **📋 Мониторинг** | Топ процессов | Таблица по CPU/RAM, обновление по кнопке |

## 📥 Установка

> ⚠️ **Только Windows** — используются WinAPI (pycaw, comtypes, LockWorkStation и др.)

**1. Клонировать репозиторий:**
```bash
git clone https://github.com/manypon/ManyDeck
cd ManyDeck
```

**2. Установить зависимости:**
```bash
pip install -r requirements.txt
```

**3. Создать `.env` и заполнить:**
```env
BOT_TOKEN=сюда_токен_от_BotFather
OWNER_ID=сюда_твой_telegram_id
```

- Токен — [@BotFather](https://t.me/BotFather)
- ID — [@Get_myidrobot](https://t.me/Get_myidrobot)

**4. Запустить:**
```bash
python bot.py
```

### Запуск без окна консоли

```bash
pythonw.exe bot.py
```

Никакого окна, никакой иконки в трее — процесс работает в фоне как `pythonw.exe`.

### Автозапуск с Windows

1. `Win + R` → `shell:startup`
2. Создай ярлык на `pythonw.exe`, в поле «Объект»:
   ```
   C:\Путь\до\pythonw.exe C:\Путь\до\ManyDeck\bot.py
   ```

## 🔐 Безопасность

- **Не публикуй `.env`** с реальным токеном. Добавь в `.gitignore`.
- Если токен утёк — немедленно отзови в [@BotFather](https://t.me/BotFather) командой `/revoke`.
- Бот отвечает только аккаунту с `OWNER_ID` из `.env`.
