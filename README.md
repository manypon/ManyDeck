# 🖥️ ManyDeck

**ManyDeck** — это удобная и полностью работоспособная панель в Telegram для удалённого управления вашим компьютером. Управляйте ПК, мониторьте нагрузку и настраивайте систему прямо из чата с ботом.

## ✨ Возможности

Все команды доступны прямо из интерфейса Telegram-бота. Вот что умеет ManyDeck:

| Категория | Действие | Описание |
| :--- | :--- | :--- |
| **🖥️ Управление ПК** | Запуск программ | Запуск приложений по их имени |
| | Ввод текста | Ввод текста в активное окно |
| | Ввод текста + Enter | Ввод текста и мгновенное нажатие Enter |
| | Блокировка | Блокировка компьютера (Win+L) |
| | Спящий режим | Отправка ПК в сон (требуется активная гибернация) |
| | Перезагрузка | Перезагрузка компьютера |
| | Выключение | Выключение компьютера |
| **📊 Мониторинг** | Нагрузка на систему | Информация о нагрузке на CPU, RAM и диски |
| | Список процессов | Просмотр запущенных процессов и их PID |
| | Скриншот | Получение снимка экрана прямо в чат бота |
| **🔊 Звук** | Громкость | Установка определённого уровня громкости |
| | Mute / Unmute | Полное выключение или включение звука |
| **⚙️ Процессы** | Убить процесс | Завершение процесса по имени или PID |
| **🧪 Отладка** | Вызов ошибки | Принудительный вызов окна с ошибкой |

## 📦 Зависимости

Для работы программы потребуются следующие библиотеки Python:

- `python-telegram-bot>=21.0`
- `psutil`
- `pyautogui`
- `pyperclip`
- `pycaw`
- `comtypes`

## 📥 Установка и использование

> ⚠️ **Важно:** Проект работает только на **Windows**, так как использует системные API (pycaw, comtypes, Win+L).

1. **Клонируйте репозиторий:**
   `git clone https://github.com/manypon/ManyDeck`
   `cd ManyDeck`

2. **Установите зависимости:**
   `pip install -r requirements.txt`

3. **Настройте конфигурацию:**
   В файле `config.py` укажите ваши данные:
   - **Токен бота** — получите у [@BotFather](https://t.me/BotFather)
   - **Ваш ID** — узнайте у [@Get_myidrobot](https://t.me/Get_myidrobot) *(это нужно для того, чтобы бот слушался только вас)*

4. **Запустите бота:**
   `python bot.py`

## 🔐 Безопасность

- **Никогда не публикуйте файл `config.py` с вашим реальным токеном.** Добавьте его в `.gitignore`.
- Если токен каким-то образом утёк — немедленно отзовите его в [@BotFather](https://t.me/BotFather) с помощью команды `/revoke`.
